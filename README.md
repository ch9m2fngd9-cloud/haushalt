# Haushalt – Steuer-Belege

Web-App zum Sammeln steuerrelevanter Daten pro Jahr, Person und Unternehmen,
mit monatlichen oder einmaligen Beträgen und Belegen (Bilder/PDFs).

**Dieses Repository enthält nur das Programm, keine Daten.** Alles, was in der App
eingetragen wird, bleibt ausschließlich auf dem jeweiligen Gerät gespeichert.

## Auf dem iPhone nutzen

1. Die App-Adresse in **Safari** öffnen.
2. Teilen-Symbol → **„Zum Home-Bildschirm“**.
3. Ab dann immer über das Symbol öffnen (es hat einen eigenen Speicher, getrennt von Safari).

Regelmäßig **„Backup speichern“** nutzen, z.B. nach iCloud Drive.
